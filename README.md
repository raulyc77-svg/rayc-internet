# Proyecto Aplicativo Integrador

## Desarrollo Web Integrado

Proyecto desarrollado para el curso de Desarrollo Web Integrado del IESTP
"Pedro P. Díaz", utilizando Laravel y Bootstrap.

## Descripción

Este proyecto aplicativo integrador utiliza Laravel como framework de
desarrollo e integra Bootstrap para el diseño de la interfaz web.

El proyecto presenta una página principal con portada y menú de navegación,
además de una página About.

## Tecnologías utilizadas

- Laravel
- Bootstrap
- PHP
- HTML
- CSS
- JavaScript
- Vite

## Características

- Página principal del proyecto.
- Portada y menú principal.
- Diseño basado en Bootstrap.
- Página About.
- Integración de Bootstrap con Laravel.
- Configuración de archivos CSS.
- Configuración de archivos JavaScript.
- Configuración de Vite.

## Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/raulyc77-svg/rayc-internet.git
```

### 2. Ingresar al proyecto

```bash
cd rayc-internet
```

### 3. Instalar las dependencias de PHP

```bash
composer install
```

### 4. Instalar las dependencias de JavaScript

```bash
npm install
```

### 5. Ejecutar Vite

```bash
npm run dev
```

### 6. Iniciar el servidor de Laravel

En otra terminal:

```bash
php artisan serve
```

### 7. Abrir el proyecto

Ingresar desde el navegador:

```text
http://127.0.0.1:8000
```
